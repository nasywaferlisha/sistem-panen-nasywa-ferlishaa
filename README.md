# Sistem Pencatatan Hasil Panen Digital

## Deskripsi
Program sederhana untuk mencatat hasil panen dan menghitung total hasil panen serta total setelah diskon.

## Cara Menjalankan Program
1. Pastikan Python sudah terpasang.
2. Buka file `panen.py`.
3. Jalankan program menggunakan Python.
4. Program akan menampilkan data hasil panen, total hasil panen, diskon, dan total setelah diskon.
